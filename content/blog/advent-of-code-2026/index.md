## What is it?
[Advent of Code](https://adventofcode.com/) is an annual set of Christmas-themed computer programming challenges that follow the story of the North Pole elves making necessary preparations for smooth festivity operations, unraveled day by day akin to how an Advent calendar is opened. It has been running since 2015. It was created by [Eric Wastl](https://was.tl/) (via Wikipedia).

## How it works
For each day from the first day of December up until the 12th day, two puzzles are dropped, the goal being to solve those puzzles with any programming language of your choice in order to obtain the stars linked to that day's puzzles. The second puzzle for each day does not unlock until the first is solved.

There is no actual code upload for the solutions. You're only required to upload the actual answers you get from solving the puzzle.

The puzzles cover a wild variety of skill levels and are a fun way to put your problem-solving skills and programming experience to the test. I first came across Advent of Code in December 2024. I haven't completed the puzzle set for any year so far, but regardless I look forward to doing so this year.

## 2026
The puzzles begin on December 1st. I plan to write about my experience solving the puzzles and document the many exciting things I will learn along the way here on my blog. The website does have a leaderboard feature, where you can create a private leaderboard and invite your friends to join. At the same time, it discourages overly publicizing your leaderboard. These events are meant to be fun and cheerful, and a large leaderboard creates a competitive tension that strains that.

As with most things recently in the programming space, human efforts are slowly taking a back seat to AI-assisted or generated coding. I personally think it robs you of the ability to genuinely enjoy and learn from the puzzles, so I will not be using AI-generated code for my solutions.

I have a public GitHub repository where I keep my solutions for all the years, and you're welcome to go through it and learn how I approach the problems [here](https://github.com/brianobot/advent-of-code-solutions). I implement my solutions in Python, Rust and Pylox, an experimental interpreted language I built while following the book *Crafting Interpreters* by Robert Nystrom.
